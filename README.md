# Kovai Car A/C website

Static site for https://kovaicarac.com, hosted on GitHub Pages.

- `index.html`, `about.html`, `gallery.html`, `contact.html` — pages
- `style.css` — all styling (no Bootstrap / jQuery needed)
- `script.js` — mobile menu, scroll animations, photo lightbox
- `img/` — images (`logo-transparent.png` is the logo without its white box)
